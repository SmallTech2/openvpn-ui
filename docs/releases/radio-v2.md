# radio-v2 — prochaine version stable, non publiée

> **radio-v2 est la prochaine version stable, encore en préparation.** Le tag et
> la Release `radio-v2` ne sont pas encore publiés. La validation complète sur Debian 13 vierge doit
> précéder la publication. `radio-v1` reste la version stable actuellement disponible.

Cette version prépare le compte administrateur Linux configurable et la validation SSH
obligatoire déjà présents sur `main`. Le comportement technique est décrit dans les
[guides](../README.md) ; la validation intégrale sur Debian 13 vierge reste à réaliser.

- [Installation et téléchargement futur](../installation.md#téléchargement-après-publication).
- [Recette avant publication](../installation.md#recette-avant-publication).
- [Administration](../administration.md), [sécurité](../security.md), [maintenance](../maintenance.md).
- [Référence stable historique radio-v1](radio-v1.md).

Les commandes utilisant le futur tag `radio-v2` sont préparées mais ne doivent pas être
exécutées avant sa publication. Aucun lien de Release ou de binaire `radio-v2` n'est
présenté comme disponible. Le commit, le tag et les empreintes seront établis lors de
la publication, après validation. Cette réorganisation ne crée ni tag ni Release.
